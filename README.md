# Controle de Gastos

Aplicação web para registrar gastos pessoais e acompanhar quanto foi gasto no total.

## Objetivo

Praticar HTML, CSS e JavaScript construindo algo que eu realmente use.

## Versão 1: o que terá

- Cadastrar um gasto com: **nome**, **descrição**, **valor** e **data**
- Listar na tela todos os gastos cadastrados
- Mostrar o **total** dos gastos, atualizado automaticamente
- Manter os gastos salvos ao recarregar a página (`localStorage`)
- **Excluir** um gasto
- **Editar** um gasto
- Validação básica dos campos (vazio, valor inválido)

## Fora da versão 1

- Filtros e categorias
- Entradas de dinheiro (a v1 registra apenas gastos)
- Banco de dados (SQL)
- Gráficos

## Tecnologias

HTML, CSS e JavaScript (sem frameworks)
